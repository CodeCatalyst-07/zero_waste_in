# Architecture Decision Records (ADR) - ZeroWasteIN

| Decision                                                                                   | Why                                                                                                                                                                                                                                                                                                                                                                                   | Alternative                                                                                                                       |
| :----------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------- |
| **Pure TypeScript, Zero-Dependency `@zerowastein/rules` Package**                          | Guarantees deterministic, fast, and completely framework-independent rule execution. Ensures legal waste segregation logic can run identically in serverless endpoints, web clients, edge runtimes, or CLI tools without supply chain overhead.                                                                                                                                       | Embedding rules directly inside API route handlers or importing heavy rule-engine libraries (e.g., json-rules-engine).            |
| **Separating Vision Attribute Extraction from Stream Decision Rules**                      | Large Language Models frequently suffer from hallucinations or regulatory drift when asked to classify statutory streams directly. Forcing AI models to extract objective physical attributes (`isBattery`, `isChemical`, `isHygiene`) and delegating stream assignment to a deterministic rules table ensures 100% legal compliance with India's SWM Rules 2026.                     | Prompting the vision model to directly output the waste stream string (`wet`, `dry`, etc.).                                       |
| **Dynamic Provider Fallback Chain (Jarvis Labs Gemma 4 -> Gemini API -> Gemma on Gemini)** | Provides high availability, cost efficiency, and resiliency against upstream outages. Leverages high-parameter Gemma 4 31B on Jarvis Labs as primary, gracefully falling back to Gemini API free tier and Gemma on Gemini without code alterations.                                                                                                                                   | Vendor lock-in to a single proprietary AI provider or single cloud vendor.                                                        |
| **Pure CSS Custom Properties (Design Tokens) with Zero Component Libraries**               | In Indian mobile contexts with fluctuating 3G/4G bandwidth, minimizing bundle payload and script execution time is critical. Plain CSS delivers instantaneous First Contentful Paint (FCP) and full control over accessible high-contrast color ratios.                                                                                                                               | Using Tailwind CSS, MUI, Chakra UI, or Ant Design, which add substantial runtime or build-time bundle weight.                     |
| **Self-Hosted Typography (`Bricolage Grotesque` & `Instrument Sans`)**                     | Eliminates external font CDN DNS lookups, avoids third-party tracking, guarantees offline availability, and provides a distinctive, non-generic brand aesthetic.                                                                                                                                                                                                                      | Loading Google Fonts or Adobe Typekit via external `<link>` tags.                                                                 |
| **Strict Server-Side Secret Isolation and Automated Leak Scanning**                        | Prevents accidental credential theft and quota depletion. Enforces that no secret keys can be bundled with client code via an automated Vitest static scanner in CI.                                                                                                                                                                                                                  | Allowing client-side API calls with exposed API tokens or public keys.                                                            |
| **Versioned Carbon Emission Factors with Explicit Sources and Years**                      | Provides scientific credibility, verifiability, and regulatory auditability for avoided greenhouse gas emission metrics (citing CPCB, TERI, and IPCC).                                                                                                                                                                                                                                | Using hardcoded, unreferenced heuristic multiplier estimates.                                                                     |
| **pnpm Workspace Monorepo Architecture**                                                   | Enables atomic cross-package TypeScript type sharing (e.g. `Attributes` shared between `@zerowastein/rules` and `api/providers`) with disk-efficient hard linking.                                                                                                                                                                                                                    | Multi-repo architecture or npm/yarn monorepo with slow installs and duplicate dependency trees.                                   |
| **Hazard Attributes Override the Table**                                                   | Public health and worker safety take precedence over material classification. Any item containing batteries, chemicals, sharps, bulbs, or electronics must be segregated into special-care regardless of label to prevent fires and toxic exposure. Known trade-off is over-routing to special-care if a model wrongly sets a hazard flag; to be tuned on a labelled photo set later. | Relying solely on item names and ignoring physical hazard flags.                                                                  |
| **Dry is the Residual Stream**                                                             | Per India's SWM Rules 2026, wet, sanitary, and domestic hazardous streams have strict positive inclusion criteria. Any non-hazardous item that is not organic or sanitary falls by statutory definition into the dry stream.                                                                                                                                                          | Creating an undefined or unclassified fallback stream.                                                                            |
| **Confidence Thresholds as Tunable Placeholders**                                          | Named constants (`CONFIDENCE_ASK = 0.50`, `CONFIDENCE_HIGH = 0.80`) centralize classification boundaries for future calibration against labelled Indian household waste test datasets without touching engine logic.                                                                                                                                                                  | Hardcoding magic numeric constants across conditional blocks.                                                                     |
| **No Bin Colors or Statutory Rule Numbers in User-Facing Data**                            | Municipal bin colors vary across Indian cities, and legal clause numbers (e.g. Rule 3(1)(zx)) confuse households. Referring neutrally to stream names per the SWM Rules 2026 and deferring colors to theme CSS tokens ensures universal applicability.                                                                                                                                | Hardcoding green/blue/red labels and specific legal rule clause numbers in user responses.                                        |
| **Plain Fetch for Jarvis Labs instead of an SDK**                                          | Keeps the serverless bundle lean and dependencies minimal. The OpenAI SDK brings extensive unneeded dependencies, while Jarvis Labs provides a standard OpenAI-compatible `/chat/completions` REST interface natively consumed via Node `fetch` with `AbortController`.                                                                                                               | Importing the heavy `openai` npm package or other generic client libraries.                                                       |
| **Cross-Check Only on Uncertainty or Hazards**                                             | Saves compute cost and network latency on 80%+ of common items by evaluating a single model when confident. Dispatches dual inference only when confidence is low (< 0.80) or when safety-critical hazard attributes are flagged, prioritizing accuracy and worker protection where it matters most.                                                                                  | Dual-evaluating every user request across two models unconditionally, doubling inference costs and response latency.              |
| **Text Fast Path**                                                                         | Achieves 0ms latency and 0 external model calls for unambiguous catalog queries (e.g., "banana peel", "milk pouch"). Saves API costs, eliminates network dependencies for common household items, and lays the architectural foundation for offline PWA operation in future phases.                                                                                                   | Routing all user input through an external AI model regardless of whether the query matches a known catalog alias.                |
| **Best-Effort Rate Limiting**                                                              | In serverless container environments (e.g., Vercel), instances do not share process memory, and IP headers can be spoofed without upstream edge proxy verification. In-memory token bucket rate limiting serves as lightweight defense-in-depth against runaway loops on a single container while formal protection belongs at the edge (Cloudflare/Vercel firewall).                 | Integrating external Redis/KV databases during early phases, introducing operational complexity and cold start latency.           |
| **Zero-Dependency Shared `@zerowastein/contract` Package**                                 | Decouples the HTTP/API contract from backend implementations (`api/`) and client bundles (`apps/web/`). Enables end-to-end type safety for requests, responses, and error codes without leaking server-only dependencies or Zod schemas into the browser client bundle.                                                                                                               | Duplicating TypeScript type declarations between client and server, or importing server modules into client code.                 |
| **Offline-First Client Text Mode**                                                         | Bundles `@zerowastein/rules` lookup and decision engine directly into client. Clear catalog matches resolve locally in 0ms with zero network roundtrips. Ambiguous queries use the backend API, and network failures gracefully fall back to local "Did you mean..." candidate chips rather than presenting an error barrier.                                                         | Requiring an active internet connection and API call for every typed query, or displaying error walls during network dropouts.    |
| **Canvas Re-Encode for EXIF Stripping & Image Scaling**                                    | Drawing user photos onto an off-screen HTML5 canvas scaled to 1024px and exporting to JPEG at 0.7 quality strips all geolocation, camera model, and device EXIF metadata entirely before network transmission, guaranteeing citizen privacy.                                                                                                                                          | Sending raw camera files directly with embedded GPS coordinates, or importing heavy client-side EXIF-stripping libraries.         |
| **Hash-Based Tabs Instead of a Router Library**                                            | Using native URL hashes (`#sort`, `#impact`) with `hashchange` listeners provides instant, accessible tab navigation with zero external router library overhead, keeping the client bundle lean and First Contentful Paint immediate on low-end Indian mobile devices.                                                                                                                | Importing heavy SPA routing libraries (React Router, TanStack Router) for a simple two-tab interface.                             |
| **No Service Worker in Phase 2.3**                                                         | Focuses Phase 2.3 on high accessibility, solid UI state machine behavior, and on-device storage. Deferring service worker caching avoids premature cache invalidation bugs and stale API proxying during active frontend iteration.                                                                                                                                                   | Registering an aggressive service worker cache early, complicating debugging and network fallback testing.                        |
| **Omission of Unverified Factors (Food, Rail/Metro, LPG)**                                 | Indian residential lifecycle factors for food consumption, metro rail, and household LPG vary widely by state and lack standardized national baseline databases. We strictly omit unverified factors and cite only authoritative sources: CEA Database v22.0 (FY25-26 electricity), India GHG Program 2015 draft (transport), and CPHEEO/JJM (water planning norms).                  | Inventing heuristic numbers or transposing European/US lifecycle factors, which undermines public trust and scientific integrity. |
| **Own-Baseline Comparison for Utilities**                                                  | Household power and water usage in India depend heavily on regional climate, household size, and building envelope. Imposing a single national consumption target would be arbitrary and inaccurate. Tracking change against the user's own immediate previous month provides authentic, actionable personal feedback.                                                                | Comparing citizens against arbitrary national benchmarks or peer-group averages that ignore climate zones.                        |
| **Transparent Eco Score Formula & Renormalization**                                        | Published, transparent formula: Sorting habit (40%), Electricity trend (25%), Water trend (15%), Transport trend (20%). Renormalizes weights over available inputs only (e.g. 1 input = 100% weight) and shows no score until real data exists. Accompanied by prominent disclaimers that it is a personal guide, not official scientific scoring.                                    | Opaque "black-box" AI score rings, fake streaks, or penalizing users for metrics they haven't logged.                             |
| **Inline SVG Charts with Accessible Table Alternatives**                                   | Third-party charting libraries (Chart.js, Recharts) add 150KB–400KB to the web bundle and often fail screen-reader accessibility. Small inline SVG bar charts paired with a togglable semantic `<table>` alternative and text summary achieve 0KB dependency overhead and 100% WCAG AA compliance.                                                                                    | Importing heavy JavaScript charting libraries or rendering inaccessible canvas charts without data table alternatives.            |
